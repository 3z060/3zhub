# 3zhub

تطبيق شخصي للآيفون يعرض لك أحدث الأدوات والأكواد الصاعدة في GitHub، مصنفة في 20 مجالاً، ومع كل أداة:
نبذة، مميزات، مواصفات، أكواد التثبيت والاستخدام، وطريقة الاستفادة منها.

**مجاني بالكامل**: يعمل على GitHub Actions + GitHub Pages، بدون سيرفر وبدون App Store.

## كيف يعمل

```
كل ساعة ← GitHub Actions يشغّل scripts/build-data.mjs
          ├─ يبحث في GitHub عن المستودعات الجديدة الصاعدة (+ استعلام لكل مجال)
          ├─ يصنفها حسب الوسوم والوصف ولغة البرمجة (scripts/categories.mjs)
          ├─ يستخرج المميزات وأكواد التثبيت والاستخدام من README (scripts/readme.mjs)
          ├─ يلخصها بالعربي مجاناً عبر GitHub Models إن توفر (scripts/ai.mjs)
          ├─ ينشر الموقع على GitHub Pages
          └─ يرسل تنبيهاً فورياً لكل مجال فيه أدوات جديدة عبر ntfy
```

## التثبيت على الآيفون

1. افتح رابط التطبيق في **Safari**.
2. اضغط زر **المشاركة** ثم **إضافة إلى الشاشة الرئيسية**.

## التنبيهات الفورية

1. ثبّت تطبيق **ntfy** المجاني من App Store.
2. في 3zhub افتح **الإعدادات** وفعّل 🔔 للمجالات التي تريدها.
3. انسخ اسم القناة لكل مجال واشترك فيها من ntfy.

بادئة القنوات تُضبط من متغير المستودع `NTFY_PREFIX`
(Settings ← Secrets and variables ← Actions ← Variables).

## التشغيل محلياً

```bash
GITHUB_TOKEN=$(gh auth token) npm run build   # جلب البيانات
node scripts/serve.mjs                        # http://localhost:5173
```

## ملاحظات

- GitHub يوقف المهام المجدولة إذا لم يحدث أي نشاط في المستودع لمدة 60 يوماً، ويرسل لك إيميلاً قبلها.
  لإعادة التشغيل: تبويب **Actions** ← **تحديث 3zhub** ← **Enable workflow**.
- الملخص الذكي يستخدم الحد المجاني من GitHub Models (12 أداة كل ساعة). إذا انتهى الحد يعمل التطبيق بالاستخراج التلقائي من README.
